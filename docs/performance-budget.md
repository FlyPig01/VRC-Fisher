# 性能与存储预算

## 1. 口径

当前已有可构建的 C# 分层工程和测试，但没有两个有效 ONNX、正式 Setup 或真实捕获适配。本文数字仍是首版预算和验收门槛，不是实测结果。发布时必须用实际 Setup、安装目录和现场运行测量替换 Release 说明中的估算。

## 2. 开发机存储

各环境独立估算，不能把它们与用户安装体积混为一谈：

| 项目 | 预计占用 | 主要来源 |
|---|---:|---|
| C# 应用开发 | 1-3 GB | .NET SDK、NuGet 缓存、Debug/Release/publish 产物 |
| 数据处理环境 | 0.3-1 GB | Python 3.11、PyAV、NumPy、Pillow、测试依赖 |
| CPU 训练环境 | 1-3 GB | PyTorch、Ultralytics、ONNX 及缓存 |
| CUDA 训练环境 | 额外数 GB | CUDA 版 PyTorch 与相关运行库，当前不安装 |
| 录屏、帧和数据集 | 数 GB 至数十 GB | 完全取决于时长、分辨率、抽帧间隔与实验数量 |
| 训练结果 | 每次数十 MB 至数百 MB | `.pt`、图表、日志和中间结果 |

同一张图片可能依次存在于抽帧、生成数据集和划分后数据集中，因此数据空间不能只按原视频大小估算。大文件均由 `.gitignore` 排除，但仍占开发机磁盘。

## 3. 用户端存储

| 项目 | 首版目标 |
|---|---:|
| 单个 Setup，内含 CPU-only 与 DirectML 两种可选组件 | 150-350 MB |
| CPU-only 安装，不含模型 | 160-280 MB |
| DirectML 安装，不含模型 | 180-320 MB |
| 两个 YOLO11n ONNX | 预计 20-30 MB，待导出实测 |
| 安装目录含模型 | 目标低于 500 MB |
| Setup 硬上限 | 低于 1 GB |

Setup 同时压缩两套发布源，所以下载体积大于最终只安装一种组件的体积。两套目录中重复的 .NET 与 WinUI 文件通常能被压缩器去重压缩，但准确数字只能在 C# publish 后得到。

模型不放进 Setup。用户可以在软件中随时下载、更新或删除两个 ONNX，所有操作只影响安装目录下的 `models/`。

## 4. 运行资源

| 指标 | 首版目标 |
|---|---:|
| 空闲 WinUI 界面内存 | 100-180 MB |
| 完整识别运行内存 | 250-450 MB |
| 静止界面 CPU | 小于 1% |
| CPU-only 总 CPU | 小于 25% |
| DirectML 总 CPU | 小于 10% |
| DirectML 额外显存 | 小于 500 MB |
| 诊断预览额外 CPU | 不超过 3% |
| UI 更新 | 5-10 Hz |
| 诊断预览 | 默认关闭，最多 5 FPS |
| 识别管线 | 目标 30 FPS，不积压旧帧 |

这些百分比依赖具体 CPU、分辨率、模型输入尺寸和 VRChat 负载。它们用于判断方案是否需要优化，不是对所有电脑的保证。

DirectML 也可能在小模型上因 GPU 调度与数据拷贝开销而不如 CPU；`Auto` 必须通过实际基准选择或可靠回退，不能仅看到 GPU 就宣称更快。CPU-only 包仍需保留，因为它依赖更少，在不兼容或 GPU 争用严重的电脑上可能更稳定。

## 5. 时间与实时性

实时性以“画面产生到决策完成的帧龄”衡量，而不是只看单次 ONNX 推理时间。需要记录：

- 屏幕捕获间隔；
- locator 与 minigame 各自推理 p50/p95；
- 预处理、后处理和裁剪耗时；
- 决策时帧龄 p50/p95；
- 丢帧数量和连续落后时长；
- VRChat 本身的帧时间变化。

缓冲只保留最新帧。处理能力低于捕获速率时丢弃旧帧，而不是排队等待；自动控制宁可降低检测频率，也不能使用几百毫秒前的状态。

## 6. 测试矩阵

正式模型产生后，在相同录屏和现场场景下分别测试：

| 安装组件 | 软件设备选项 | 应验证的实际 Provider |
|---|---|---|
| CPU-only | Auto | CPU |
| CPU-only | CPU | CPU |
| DirectML | Auto | DirectML 或有记录的 CPU 回退 |
| DirectML | CPU | CPU |
| DirectML | GPU | DirectML；失败必须报告 |

每组至少记录软件版本、模型版本、显示器分辨率、CPU/GPU、VRChat 状态、内存峰值、CPU、GPU、显存、推理 p95、帧龄 p95 和丢帧率。

## 7. 发布门槛

以下任一情况发生时不得发布：

- 安装目录或 Setup 达到 1 GB；
- 内存持续增长；
- 空闲界面持续占用明显 CPU；
- 推理队列积压旧帧；
- DirectML 初始化失败却仍显示 GPU 正常；
- 开启或关闭 GUI 明显改变识别正确性；
- 默认诊断预览显著影响 VRChat 帧率；
- 资源数字来自估算而非正式构建实测。
