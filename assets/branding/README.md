# Branding assets

`VRC-Fisher.svg` is the revised application icon concept. It uses an explicit
fish silhouette, fishing line and hook, tracking brackets, and water waves so
the subject remains recognizable when reduced. It is an original vector source
asset for visual review only. It is not referenced by the WinUI application or
Inno Setup yet, and no `.ico` has been generated. After the visual design is
approved, export the required Windows icon sizes from this source and update
the packaging manifest in a separate change.
